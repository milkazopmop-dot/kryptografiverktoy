# Kryptografiverktøy

Et skoleprosjekt laget med SvelteKit.

## Del 1 – Caesar

Programmet kan kryptere og dekryptere tekst med Caesar.
Nøkkelen må være et heltall fra 0 til 25.

Store og små engelske bokstaver støttes.
Mellomrom beholdes på samme sted.
Ved ugyldig tekst eller nøkkel vises en feilmelding.

## Starte prosjektet

Node.js og npm må være installert.

Kjør i prosjektmappen:

```bash
npm install
npm run dev
```

Åpne adressen som vises i terminalen.
